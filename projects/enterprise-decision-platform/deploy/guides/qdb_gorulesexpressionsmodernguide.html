Expression output structure

Each node returns an object. Define a field name on the left and the expression that calculates its value on the right.

02
Expression output 
// Each field becomes part of the output object
{
  "subtotal": order.price * order.quantity,
  "discount": customer.tier == "Gold" ? 0.15 : 0,
  "displayName": user.nickname ?? user.name ?? "Anonymous",
  "approved": score >= 70 and not isBlocked
}
Field name The property added to the output object, such as subtotal.
Expression The calculation, lookup, condition, or function that determines the value.
Output object The complete object passed to downstream nodes after all fields are evaluated.

Access input and upstream data

Use dot notation for normal fields, brackets for arrays or names with spaces, and $nodes for earlier node outputs.

Array indexing

Select an item by position, starting with index zero.

order.items[0].price
$

Previous-node output

Reference an upstream node by its name.

$nodes.CreditCheck.rating
💡
Node names containing spaces Use bracket notation, for example $nodes["Risk Assessment"].score.

Common expression patterns

Use these patterns as a starting point for frequently needed transformations.

06
Σ

Calculate totals

Multiply each item price by quantity and add the results.

sum(map(order.items,
  #.price * #.quantity
))
A

Categorize values

Assign a readable category from a numeric score.

score >= 80 ? "High" :
score >= 50 ? "Medium" :
"Low"
D

Work with dates

Calculate the number of days since a known date.

d().diff(
  customer.createdAt,
  "day"
)
