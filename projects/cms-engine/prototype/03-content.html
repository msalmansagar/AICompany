Pages store an asset key, never a URL or a CSS value. Replacing a placeholder with real photography updates qdb_cmsmediaasset and every page that references it picks up the change untouched — no page is edited, no version is created.
✨
Icons work exactly like photos: a page stores the icon's name, and this library holds the actual shape. Swap an icon here and every page using it updates — no page is edited, no version created. Power admins can upload their own, so a new icon does not wait on a developer.
🛡
Why uploads are checked. An SVG file is not really a picture — it is a small program, and a malicious one can run code on the portal when a visitor opens the page. Every upload is stripped of scripts, event handlers and external references before it is stored. Rejected files are logged, not silently dropped.
⚠️
Stale means the English source changed after the Arabic was written. The engine keeps a hash of the source string at translation time; when the source moves, the pair is flagged rather than silently serving an out-of-date translation.
