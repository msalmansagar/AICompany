Where this stops. Anything you can express by arranging existing blocks, you can build here. Something genuinely new — a live map, a payment widget, a chart bound to live data — still needs a developer to add a new brick. In practice that is rare: the 13 basic blocks cover almost everything, and each new brick a developer adds multiplies what can be built here without them.
