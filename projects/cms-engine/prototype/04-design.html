Versioning rule

Why adding a prop is not free
Stored pages carry the props they were saved with. A prop added in a later component version does not back-fill existing pages — those pages simply lack it.

Every component render must therefore tolerate a missing prop, or publish must run a migration. The registry records which version each page was authored against so the gap is detectable rather than a surprise at render time.
