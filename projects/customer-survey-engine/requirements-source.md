AC1: Survey Types

CRM Administrators can create and manage survey types.

AC 1,1 Survey type must be either " Milestone" or "Quarterly" or Monthly or Annually

AC 1.2 Option to select channel type Option "Digital" or Legacy. By default, Digital

AC 1.3 Select mode "applications "or "Transactions"

AC1.4 in case of applications select Application type (Multi select) :1. New STF 2. New LTF, 3. renewal
4.Rescheduling 5 Limit increase 6 renewal cum limit increase 7 Extension of drawdown.

AC 1.5 In case of transactions, select type 1. WBS 2. LC 3. Fund transfer (Multi select option)

AC2: Survey Questions

CRM Administrators can create and manage survey questions.

AC 2.1 each question must have theme option set as 1. UI and Navigation 2. Requirements clarity 3. Overall experience

AC 2.2 CRM admin chooses one theme and can add questions for the theme selected

AC 2.2 Next Answers must have two options 1. Single selection 2. Multiple selection 3 Open text

AC 2.3 In case of Single selection or multiple selection Options must be provided based on theme

AC 2.4 Based on themes, Answer option set mapping is attached. Also, Incase Admin wants to enter a new option set, he must have an option to do.

AC3: Question Order

Administrators can define the order in which survey questions are displayed.

AC5: Survey Status

Administrators can activate or deactivate surveys.

AC6: Application Submission Trigger

Administrators can configure surveys to be triggered on application submission.

AC7: Application Decision Trigger

Administrators can configure surveys to be triggered on application decisions.

AC 7.1 In case of application decision, Option set must be provided to choose, 1. Facility creation

AC8: Disbursement Submission Trigger

Administrators can configure surveys to be triggered on disbursement submission.

AC9: Disbursement Completion Trigger

Administrators can configure surveys to be triggered on disbursement completion.

AC10: Quarterly Survey Trigger

Administrators can configure surveys to be triggered on a quarterly basis.

AC11: Notification Title

Administrators can configure the notification title for each survey type.

AC12: Notification Content

Administrators can configure the notification message displayed to customers.

AC13: Survey Activation Period

Administrators can configure the period during which a survey is available to customers.

AC14: Survey Expiry

Administrators can configure the survey expiry period.

AC 14.1 In case of Quarterly survey, it must be active until 1 month of the next quarter incase it's not submitted

AC15: Survey Generation

A survey is automatically generated when the configured trigger conditions are met.

AC16: Configuration Updates

Changes to survey configurations are applied to newly generated surveys.

AC 17 Milestones configurations or

There must be a counter to select the survey milestone after every < Number > for all applications or <configured > numbers
